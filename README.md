# Techstoresv

Proyecto de simulacion de modulo de inventario de productos de una tienda en linea.

El objetivo del proyecto es mostrar una forma optimizada de manejar control de inventario de productos ante una alta demanda.

El proyecto no incluye una base de datos real, utiliza localStorage, las funciones de obtener datos no funcionan igual, pero siempre se implemento en un service.

This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 21.2.13.

This project includes [Angular Material](https://material.angular.dev)
